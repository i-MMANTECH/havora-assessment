# HAVORA Profile Setup Assessment

A modern, multi-step profile setup screen built for the HAVORA Software Engineer (Volunteer) assessment.

## Features Included
- **Step 1: Welcome Screen** with pulsing branding logo.
- **Step 2: Create Profile** with required field validation.
- **Step 3: Relationship Intention** single-select flow.
- **Step 4: Core Values** multi-select grid (maximum 5 selections).
- **Step 5: Profile Summary** screen displaying all collected information.
- **Bonus Features:** 
  - Dark Mode support (toggle at top right)
  - Animated progress bar
  - Smooth page transitions and hover effects
  - Fully responsive, mobile-first layout

## Technology Stack
- React (via Vite)
- Vanilla CSS (for rich aesthetics and glassmorphism)
- No backend required (state managed locally via React hooks)

## Local Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/i-MMANTECH/havora-assessment.git
   cd havora-assessment
   ```

2. **Install dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser to preview the application.
